# Copilot-Studio

AI agents and automations built on Microsoft Copilot Studio + Power Platform,
integrating Microsoft 365 (Outlook, Teams, SharePoint) with Atlassian Jira
Cloud.

## Projects

- [`manco-capture/`](./manco-capture) — Capture Agent that turns leadership
  emails and Teams meeting transcripts into Jira Tasks on the Manco Board,
  with human approval in Teams.
